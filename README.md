# Quiz Application

## About the Project
This is a simple console-based Quiz Application developed using Python. It allows users to create quizzes, answer multiple-choice questions, search for quizzes, and view their scores.

## Features
- Create a new quiz with multiple-choice questions.
- View all available quizzes.
- Search quizzes by title or topic.
- Take a quiz and calculate the score.
- Save quiz results.
- View previous quiz results.
- Store quiz and result data using JSON files.
- Handle invalid user inputs.

## Technologies Used
- Python
- JSON
- Object-Oriented Programming
- VS Code

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python src/main.py
```

5. Select an option from the menu to use the application.
